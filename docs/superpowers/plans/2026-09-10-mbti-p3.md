# P3 — 16가지 성격유형 테스트 + 모듈 뷰 위임 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 두 번째 테스트(16가지 성격유형, MBTI형)를 모듈로 추가하고, 공용 요약/비교 카드가 "레이더 고정" 대신 모듈의 시각화를 렌더하도록 확장한다(하이브리드 검증). OCEAN 회귀 없음. 상표 안전(원작 문항·"16가지 성격유형 검사").

- [ ] **Step 3: `tests/mbti/module.js` — MBTI_MODULE**

```js
// 전역 의존: MBTI_QUESTIONS·MBTI_AXES·MBTI_SCALE(questions.js), MBTI_TYPES(types.js).
const MBTI_MODULE = {
  meta: { id: "mbti", name: "16가지 성격유형 검사", tagline: "네 갈래로 나를 읽는 16유형 검사",
          icon: "🧭", scaleSize: 5, scaleLabels: MBTI_SCALE.map((s) => s.label) },
  questions: MBTI_QUESTIONS,
  // 축별 합산 → 두번째 글자(I/N/F/P) 비율(%) 0~100. 미응답 중립(3).
  score(answers) {
    const sum = { EI: 0, SN: 0, TF: 0, JP: 0 }, cnt = { EI: 0, SN: 0, TF: 0, JP: 0 };
    MBTI_QUESTIONS.forEach((q, i) => {
      const v = answers[i] ?? 3;
      const dir = q.keyed === "+" ? v : 6 - v;   // 클수록 두번째 글자 쪽
      sum[q.axis] += dir; cnt[q.axis] += 1;
    });
    const scores = {};
    Object.keys(sum).forEach((a) => {            // 평균(1~5) → 0~100 %(두번째 글자 비율)
      const avg = cnt[a] ? sum[a] / cnt[a] : 3;
      scores[a] = Math.round(((avg - 1) / 4) * 100);
    });
    return scores;   // { EI, SN, TF, JP } : 각 축 두번째 글자(I/N/F/P) %
  },
  buildProfile(scores) {
    const letters = {};
    Object.keys(MBTI_AXES).forEach((a) => { letters[a] = scores[a] >= 50 ? MBTI_AXES[a][1] : MBTI_AXES[a][0]; });
    const code = letters.EI + letters.SN + letters.TF + letters.JP;
    const t = MBTI_TYPES[code] || {};
    return { type: { code, title: t.title || code, role: t.title || "", emoji: t.emoji || "🧭" },
             letters, scores, summary: t.summary || "", description: t.description || "",
             strengths: t.strengths || [], blindspots: t.blindspots || [], careers: t.careers || [] };
  },
  renderResult(mountEl, { scores, profile }) { /* 유형코드 대형+이모지+별명, 4 이분 바, 설명, 강점/약점, 직무 칩 */ },
  renderSummaryViz(container, scores) { /* 컴팩트 4 이분 바 */ },
  renderCompareViz(container, datasets) { /* 축별 두 값 나란히 바(색상별) */ },
};
```
(구현자: `renderResult`/`renderSummaryViz`/`renderCompareViz`의 실제 DOM 생성 코드 작성. 이분 바 = 각 축 `[첫글자 라벨] [트랙+마커(scores[a]%)] [둘째글자 라벨]`. renderResult는 mountEl.innerHTML로 자체 마크업 후 채움. 텍스트는 textContent.)
