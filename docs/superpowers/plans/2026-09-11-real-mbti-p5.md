# P5 — "진짜 MBTI 찾기" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 4번째 테스트 "진짜 MBTI 찾기"(페르소나 vs 진짜) 추가. 검사 전 "아는 MBTI" 선입력 → MBTI 엔진으로 채점 → KKTI식 결과(알던 vs 진짜·1·2위·본질×추구·반반·TOP4 랭킹·당신의 이야기). 기존 3테스트 회귀 없음.

**Architecture:** 러너에 옵션 "선입력 스텝(prelude)" 확장. real-mbti 모듈이 MBTI 32문항 엔진을 재사용(축별 %)하고 결과 로직(랭킹·반반·추구·비교·서사)을 구현. known은 scores.known(jsonb)에 병합(스키마 무변경).

**Tech Stack:** Vanilla JS(정적), Supabase(변경 없음). 검증: `node --check` + agent-browser.

**참조 스펙:** `docs/superpowers/specs/2026-09-11-real-mbti-p5-design.md`

- [ ] **Step 2: test-runner.js — prelude 흐름**

`views`에 `prelude` 추가. `state`에 `prelude: {}` 추가. 문항 시작 함수(`start`)를 감싸는 흐름:
```js
function beginTest(session) {
  state.nickname = Auth.displayName(session);
  state.userId = session.user.id;
  state.answers = new Array(test.questions.length).fill(null);
  state.prelude = {};
  if (test.meta.prelude) { renderPrelude(test.meta.prelude); show("prelude"); }
  else start();
}
function renderPrelude(p) {
  document.getElementById("prelude-title").textContent = p.title;
  document.getElementById("prelude-hint").textContent = p.hint || "";
  const box = document.getElementById("prelude-options");
  box.replaceChildren();
  const opts = [...p.options, ...(p.allowSkip ? [p.allowSkip] : [])];
  opts.forEach((o) => {
    const b = document.createElement("button");
    b.className = "prelude-opt" + (o === p.allowSkip ? " prelude-skip" : "");
    b.textContent = o.label;
    b.addEventListener("click", () => { state.prelude[p.key] = o.value; start(); });
    box.appendChild(b);
  });
}
```
(비로그인 게이트는 그대로 — 로그인 후 beginTest에서 prelude. `start()`는 기존대로 첫 문항 렌더 + `show("test")`.)

- [ ] **Step 3: test-runner.js — finish에서 known 병합**

## Task 2: real-mbti 모듈 + 유형별 서사

**Files:** Create `tests/real-mbti/stories.js`, `tests/real-mbti/module.js`; Modify `tests/registry.js`, `styles.css`, 5 HTML files

- [ ] **Step 1: tests/real-mbti/stories.js — 16유형 4비트 원작 서사**

```js
// 진짜 MBTI 찾기 — 유형별 "당신의 이야기"(페르소나→간극→진짜→위로). 16유형 전부.
const REAL_STORIES = {
  INTJ: { you:"…남들이 아는 당신(페르소나)…", test:"…검사가 짚은 간극…", truth:"…진짜 당신…", ok:"…위로·인정…" },
  … 16개 전부 …
};
```
(구현자: MBTI_TYPES의 각 유형 특성에 맞춰 자연스러운 원작 한국어 4비트. 각 1~2문장. "당신은/검사 결과는/사실은/괜찮습니다" 톤.)

- [ ] **Step 2: tests/real-mbti/module.js — REAL_MBTI_MODULE**

의존: 전역 `MBTI_QUESTIONS·MBTI_AXES·MBTI_TYPES`(mbti), `REAL_STORIES`, `_renderDichBars`(있으면 재사용; 없으면 자체 바). 로드 순서 mbti → real-mbti.

```js
const KEIRSEY = { NT:"전략적", NF:"이상적", SJ:"체계적", SP:"실전적" };
function _temperament(code){ const N=code[1]==="N", F=code[2]==="F", J=code[3]==="J";
  if(N) return F?"NF":"NT"; return J?"SJ":"SP"; }
function _agree(scores, code){ // code 각 글자 쪽 사용자 % 평균
  const ax=["EI","SN","TF","JP"]; let s=0;
  ax.forEach((a,i)=>{ const second=code[i]===MBTI_AXES[a][1]; s += second?scores[a]:100-scores[a]; });
  return s/4;
}
const ALL16 = [/* 16 codes */];
```
- `meta`: id "real-mbti", name "진짜 MBTI 찾기", icon "🕵️", scaleSize 5, scaleLabels, introLead, durationMin 5, sampleQuestion, faq(공식 MBTI®와 별개 명시), **prelude**{ key:"known", title:"당신이 알고 있는 MBTI는?", hint:"검사가 찾은 '진짜'와 비교해 드려요", options: ALL16.map(c=>({value:c,label:c})), allowSkip:{value:"UNKNOWN",label:"잘 모르겠어요"} }.
- `questions: MBTI_QUESTIONS`.
- `score(answers)`: MBTI 채점 로직(축별 %). (mbti의 `_mbtiScore`가 전역이면 재사용, 아니면 동일 계산 복제.)
- `buildProfile(scores)`:
  - real code = 축별 `>=50?2nd:1st`.
  - ranking: ALL16 → {code, raw:_agree(scores,code)}; raw 내림차순; top=raw[0].raw; pct=round(raw/top*100); TOP4. real=ranking[0].code(=code), second=ranking[1].
  - banban: 축 `Math.abs(scores[a]-50)<=10`.
  - pursuit: group=_temperament(second.code); phrase=`같은 ${type.title||code} 중 가장 ${KEIRSEY[group]}(${group})인 유형`.
  - known: scores.known && scores.known!=="UNKNOWN" ? { code:scores.known, rank: ranking.findIndex(r=>r.code===scores.known)+1 } : null.
  - type = MBTI_TYPES[code] 기반 {code,title,role,emoji}.
  - return { type, letters, scores, ranking(TOP4 with badge: 1위 'ME', known code '기존'), banban, pursuit, known, story: REAL_STORIES[code] }.
- `renderResult(mountEl,{scores,profile})`: 다크 카드로 KKTI 순서 렌더(스펙 §2). 텍스트 textContent. 알던vs진짜 글자 타일(다른 글자 강조), 1·2위 %, 본질×추구 phrase, 축별 %+반반 바, TOP4 랭킹(뱃지·알던 것 위치 문구), 당신의 이야기 4비트(👁🔎💡❤️).
- `renderSummaryViz(container,scores)`: 진짜 유형 이분 바(재사용) + known 뱃지.
- `renderCompareViz(container,datasets)`: MBTI 비교 바 재사용.
- (선택) `renderDiscoverPreviews(grid)`: 5카드.
